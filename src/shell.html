Language and API reference

Carts follow the Bidule 01 technical specification. Each cart holds its source plus asset sections (sprite sheet, maps, sounds, palette) laid out as the spec defines. This emulator interprets source directly; checks the spec places at compile time are reported when the line first runs.

LIFECYCLE

update(frame, input) every frame, 60 Hz
draw(frame, input) after update
audio(t) bytebeat at 8 kHz, returns 0–255
